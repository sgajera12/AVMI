## 🔧 If Something Goes Wrong

### Problem: "No synchronized frames found"

**Check topic names:**
```bash
ros2 bag info /mnt/user-data/uploads/run1_lidar_camera_0.db3
```

**Fix:** Edit `ugv_fusion_node.py` lines 111-112 to match your actual topic names.

### Problem: Points are misaligned

**This means calibration needs adjustment.**

1. Double-check sensor positions in Unreal Engine
2. Try different coordinate conversions in `_setup_calibration()`:

```python
# Original (camera below and forward of LiDAR):
self.t_l2c = np.array([1.878, 0.0, -0.764], dtype=np.float32)

# Try these alternatives if misaligned:
# Flip X:
self.t_l2c = np.array([-1.878, 0.0, -0.764], dtype=np.float32)

# Flip Z:
self.t_l2c = np.array([1.878, 0.0, 0.764], dtype=np.float32)

# Flip both:
self.t_l2c = np.array([-1.878, 0.0, 0.764], dtype=np.float32)
```

### Problem: No points visible

**Debug steps:**
1. Run test script first: `python3 test_fusion.py <your_bag>`
2. Check point cloud range in output
3. Verify points are in front of camera (Z > 0)

## 📊 Understanding the Outputs

### Output 1: `/fusion/projected_image` (Depth-Colored)
- Original image with colored dots
- **Blue** = Close (0-5m)
- **Green** = Medium (5-15m)
- **Red** = Far (15m+)

**Use case:** Quick depth visualization, obstacle detection

### Output 2: `/fusion/color_projection_image` (RGB-Colored)
- Black background with colored dots
- Dot colors match image pixel colors
- **Use case:** Verify calibration accuracy

**Good calibration:**
```
Green dots on grass ✅
Brown dots on tree trunk ✅
Blue dots on sky ✅
```

**Bad calibration:**
```
Green dots on tree trunk ❌ (should be brown)
Brown dots on grass ❌ (should be green)
→ Calibration is off! Adjust sensor positions.
```

## ⏭️ Next Steps

After verifying everything works:

1. **Adjust playback speed:**
   ```bash
   # Slower (1 FPS)
   ros2 run ugv_fusion ugv_fusion_node --ros-args -p republish_rate_hz:=1.0
   
   # Faster (30 FPS)
   ros2 run ugv_fusion ugv_fusion_node --ros-args -p republish_rate_hz:=30.0
   ```

2. **Process different bag files:**
   ```bash
   ros2 run ugv_fusion ugv_fusion_node --ros-args -p bag_file:=/path/to/other.db3
   ```

3. **Record fusion output:**
   ```bash
   ros2 bag record /fusion/projected_image /fusion/color_projection_image
   ```
